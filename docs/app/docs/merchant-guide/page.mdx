# Merchant Guide

This guide walks merchants through creating plans, managing subscriptions, and charging on schedule.

## Overview

As a merchant, you can:
1. Create subscription plans with fixed pricing and intervals
2. View subscribers to your plans
3. Charge active subscriptions when intervals elapse
4. Track subscription status and cap exhaustion

You **cannot**:
- Charge before the interval elapses
- Exceed a subscriber's cap
- Charge cancelled, paused, or exhausted subscriptions
- Prevent subscribers from cancelling

## Creating a Plan

Plans define your subscription terms: price, token, and billing interval.

### Example: Monthly SaaS Subscription

```typescript
import { Contract, Keypair, Networks, TransactionBuilder } from "@stellar/stellar-sdk";

const merchant = Keypair.fromSecret("S...");
const planContract = new Contract(PLAN_CONTRACT_ADDRESS);

// Create a plan: 10 USDC per month
const createPlanOp = planContract.call(
  "create_plan",
  merchant.publicKey(),       // merchant address
  "Pro Plan",                  // plan name
  "100000000",                 // 10 USDC (7 decimals)
  USDC_TOKEN_ADDRESS,          // USDC contract
  2592000                      // ~30 days (2.592M ledgers)
);

const tx = new TransactionBuilder(account, {
  fee: "10000",
  networkPassphrase: Networks.TESTNET,
})
  .addOperation(createPlanOp)
  .setTimeout(30)
  .build();

tx.sign(merchant);
const result = await server.submitTransaction(tx);

// Extract plan ID from result
const planId = result.id; // Use this to reference the plan
console.log("Plan created:", planId);
```

<CalloutBox type="info">
**Billing intervals** are measured in Stellar ledgers, not wall-clock time. 1 ledger ≈ 1 second, so 2,592,000 ledgers ≈ 30 days.
</CalloutBox>

### Choosing an Interval

Common intervals:
- **Daily:** 86,400 ledgers (~1 day)
- **Weekly:** 604,800 ledgers (~7 days)
- **Monthly:** 2,592,000 ledgers (~30 days)
- **Yearly:** 31,536,000 ledgers (~365 days)

## Viewing Your Subscribers

Use the API to see who's subscribed to your plans:

```typescript
const merchantAddress = merchant.publicKey();
const response = await fetch(
  `https://api.stellar-subscriptions.io/merchants/${merchantAddress}/subscriptions`
);
const { subscriptions } = await response.json();

console.log(`You have ${subscriptions.length} subscribers`);

subscriptions.forEach(sub => {
  console.log(`- ${sub.subscriber}: ${sub.status}, charged ${sub.total_charged}/${sub.cap}`);
});
```

### Filtering Chargeable Subscriptions

```typescript
async function getChargeableSubscriptions(merchantAddress: string, currentLedger: number) {
  const response = await fetch(
    `https://api.stellar-subscriptions.io/merchants/${merchantAddress}/subscriptions`
  );
  const { subscriptions } = await response.json();
  
  return subscriptions.filter(sub => {
    // Must be active
    if (sub.status !== "active") return false;
    
    // Must have next_charge_ledger set and elapsed
    if (!sub.next_charge_ledger || currentLedger < sub.next_charge_ledger) return false;
    
    // Must not exceed cap
    const charged = BigInt(sub.total_charged);
    const amount = BigInt(sub.amount);
    const cap = BigInt(sub.cap);
    
    return charged + amount <= cap;
  });
}

// Usage
const chargeable = await getChargeableSubscriptions(
  merchantAddress,
  await getCurrentLedger()
);
console.log(`${chargeable.length} subscriptions ready to charge`);
```

## Charging Subscriptions

Charge a subscription when the interval has elapsed:

```typescript
const subscriptionContract = new Contract(SUBSCRIPTION_CONTRACT_ADDRESS);

async function chargeSubscription(subscriptionId: string) {
  const chargeOp = subscriptionContract.call("charge", subscriptionId);
  
  const tx = new TransactionBuilder(account, {
    fee: "10000",
    networkPassphrase: Networks.TESTNET,
  })
    .addOperation(chargeOp)
    .setTimeout(30)
    .build();
  
  tx.sign(merchant);
  
  try {
    const result = await server.submitTransaction(tx);
    console.log(`✅ Charged subscription ${subscriptionId}: ${result.hash}`);
    return { success: true, hash: result.hash };
  } catch (error) {
    console.error(`❌ Failed to charge ${subscriptionId}:`, error.message);
    return { success: false, error: error.message };
  }
}
```

### Handling Charge Failures

Charges can fail for several reasons:

| Error | Reason | Action |
|-------|--------|--------|
| `IntervalNotElapsed` | You tried to charge too early | Wait until `next_charge_ledger` |
| `CapExceeded` | Subscription cap is exhausted | Stop charging, subscription is complete |
| `SubscriptionNotActive` | Subscriber cancelled or paused | Stop charging, respect their choice |
| `InsufficientBalance` | Subscriber doesn't have tokens | Retry later or notify subscriber |

```typescript
async function chargeWithRetry(subscriptionId: string, maxRetries = 3) {
  for (let i = 0; i < maxRetries; i++) {
    const result = await chargeSubscription(subscriptionId);
    
    if (result.success) return result;
    
    // Don't retry on non-retryable errors
    if (result.error.includes("CapExceeded") || 
        result.error.includes("SubscriptionNotActive")) {
      console.log("Non-retryable error, giving up");
      return result;
    }
    
    // Wait before retry
    await new Promise(resolve => setTimeout(resolve, 5000 * (i + 1)));
  }
}
```

## Building an Automated Charger

A production merchant system should:

1. **Poll for chargeable subscriptions** every N minutes
2. **Respect next_charge_ledger** — don't charge early
3. **Handle failures gracefully** — log and retry appropriately
4. **Track charge history** — record successful charges
5. **Notify subscribers** — send receipts or failure notifications

### Example Worker

```typescript
async function chargeWorker() {
  console.log("Starting charge worker...");
  
  while (true) {
    try {
      const currentLedger = await getCurrentLedger();
      const chargeable = await getChargeableSubscriptions(
        merchantAddress,
        currentLedger
      );
      
      console.log(`Found ${chargeable.length} subscriptions to charge`);
      
      for (const sub of chargeable) {
        await chargeSubscription(sub.id);
        // Rate limit: don't spam network
        await new Promise(resolve => setTimeout(resolve, 2000));
      }
    } catch (error) {
      console.error("Worker error:", error);
    }
    
    // Check every 10 minutes
    await new Promise(resolve => setTimeout(resolve, 600000));
  }
}

// Start the worker
chargeWorker().catch(console.error);
```

## Handling Exhausted Subscriptions

When a subscription reaches its cap, the API marks it as `exhausted`. You should:

1. **Stop charging attempts** — they'll fail anyway
2. **Notify the subscriber** — offer to renew with a new subscription
3. **Archive the subscription** — keep records for accounting

```typescript
async function handleExhaustedSubscriptions() {
  const subs = await getSubscriptionsByStatus("exhausted");
  
  for (const sub of subs) {
    console.log(`Subscription ${sub.id} exhausted, notifying subscriber`);
    await notifySubscriber(sub.subscriber, {
      type: "cap_exhausted",
      subscription: sub,
      renewalLink: `https://your-site.com/renew?sub=${sub.id}`,
    });
  }
}
```

## Best Practices

<CalloutBox type="success">
**DO:**
- Charge on schedule when intervals elapse
- Handle failures gracefully with retries
- Notify subscribers of successful charges
- Respect cancellations immediately
- Monitor subscription health proactively
</CalloutBox>

<CalloutBox type="danger">
**DON'T:**
- Try to charge before the interval elapses
- Spam charge attempts on failed transactions
- Assume charges will always succeed
- Hide subscription terms from users
- Ignore subscriber cancellations
</CalloutBox>
