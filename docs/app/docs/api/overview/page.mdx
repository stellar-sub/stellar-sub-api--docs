# API Overview

The Stellar Subscriptions API provides a REST interface to query indexed subscription and plan data from the Stellar blockchain.

## Base URL

```
https://api.stellar-subscriptions.io
```

For local development:
```
http://localhost:3001
```

## Authentication

The API is currently **public and unauthenticated**. All endpoints are read-only (GET requests).

<CalloutBox type="info">
Rate limiting will be added before mainnet launch. Current limit: 100 requests/minute per IP.
</CalloutBox>

## Response Format

All successful responses return JSON with this structure:

```json
{
  "plans": [...],           // for /plans endpoints
  "subscriptions": [...],   // for /subscriptions endpoints
  "stats": {...}            // for /stats endpoint
}
```

Error responses:

```json
{
  "error": "Error message description"
}
```

## Status Codes

| Code | Meaning |
|------|---------|
| 200 | Success |
| 404 | Resource not found (plan or subscription ID doesn't exist) |
| 500 | Internal server error |

## Data Freshness

The API indexes data from Horizon every **10 seconds**. There may be a slight delay between on-chain events and API visibility.

<CalloutBox type="warning">
For real-time data or to verify critical information, always query the contracts directly via Soroban RPC.
</CalloutBox>

## Example: Full Subscription Flow

```typescript
// 1. List available plans
const plansResponse = await fetch("https://api.stellar-subscriptions.io/plans");
const { plans } = await plansResponse.json();

// 2. Get specific plan details
const planId = plans[0].id;
const planResponse = await fetch(`https://api.stellar-subscriptions.io/plans/${planId}`);
const { plan } = await planResponse.json();

// 3. After subscribing on-chain, query your subscription
const subId = "sub_abc123";
const subResponse = await fetch(`https://api.stellar-subscriptions.io/subscriptions/${subId}`);
const { subscription } = await subResponse.json();

console.log(`Status: ${subscription.status}`);
console.log(`Charged: ${subscription.total_charged} / ${subscription.cap}`);
console.log(`Next charge at ledger: ${subscription.next_charge_ledger}`);
```
