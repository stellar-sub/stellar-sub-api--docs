# Registry Contract

The Registry Contract maintains a global registry of all plans and subscriptions.

## Overview

This contract provides:
- Central directory of all plans
- Lookup functions for plans and subscriptions
- Cross-contract coordination

## Contract Address

**Testnet:** `CCPQJFWM2O8RZQYQZQYQZQYQZQYQZQYQZQYQZQYQ` *(placeholder)*

## Functions

### register_plan()

Called automatically when a plan is created.

### register_subscription()

Called automatically when a subscription is created.

### get_plans_by_merchant()

Query all plans by a specific merchant address.
