# Subscriber Guide

This guide helps subscribers understand how to safely subscribe, monitor usage, and manage subscriptions.

## Understanding Your Authorization

When you subscribe to a plan, you grant the merchant **limited, revocable permission** to charge your account:

- **Total cap:** The maximum amount they can ever charge you
- **Billing interval:** How frequently they can charge (e.g., monthly)
- **Instant revocation:** You can cancel anytime

<CalloutBox type="info">
Read the [Authorization Model](/docs/concepts/authorization-model) to fully understand what you're authorizing.
</CalloutBox>

## Before You Subscribe

### 1. Review the Plan

Check the plan details:

```typescript
const planResponse = await fetch(
  `https://api.stellar-subscriptions.io/plans/${planId}`
);
const { plan } = await planResponse.json();

console.log(`Plan: ${plan.name}`);
console.log(`Amount: ${parseInt(plan.amount) / 10_000_000} USDC per charge`);
console.log(`Interval: ${plan.interval_ledgers} ledgers (~${plan.interval_ledgers / 86400} days)`);
```

### 2. Calculate Your Cap

Decide how many billing cycles you want to authorize:

```typescript
const cyclesDesired = 12; // 12 months
const amountPerCharge = BigInt(plan.amount);
const cap = (amountPerCharge * BigInt(cyclesDesired)).toString();

console.log(`Cap for ${cyclesDesired} cycles: ${cap} stroops`);
```

<CalloutBox type="warning">
**Start conservative:** It's safer to authorize 3-6 months initially. You can always create a new subscription later.
</CalloutBox>

### 3. Ensure Sufficient Balance

Make sure you have enough tokens for at least the first charge:

```typescript
import { Contract } from "@stellar/stellar-sdk";

const tokenContract = new Contract(plan.token);
const balance = await tokenContract.call("balance", yourAddress);

if (BigInt(balance) < BigInt(plan.amount)) {
  console.error("Insufficient balance for first charge!");
}
```

## Subscribing to a Plan

```typescript
import { Contract, Keypair, TransactionBuilder, Networks } from "@stellar/stellar-sdk";

const subscriber = Keypair.fromSecret("S...");
const subscriptionContract = new Contract(SUBSCRIPTION_CONTRACT_ADDRESS);

// Subscribe with a 120 USDC cap (assuming 10 USDC/month)
const subscribeOp = subscriptionContract.call(
  "subscribe",
  subscriber.publicKey(),     // your address
  planId,                      // plan you're subscribing to
  "1200000000"                 // cap: 120 USDC (7 decimals)
);

const tx = new TransactionBuilder(account, {
  fee: "10000",
  networkPassphrase: Networks.TESTNET,
})
  .addOperation(subscribeOp)
  .setTimeout(30)
  .build();

tx.sign(subscriber);
const result = await server.submitTransaction(tx);

console.log("Subscription created:", result.id);
```

## Monitoring Your Subscription

### Check Cap Progress

```typescript
const subResponse = await fetch(
  `https://api.stellar-subscriptions.io/subscriptions/${subscriptionId}`
);
const { subscription } = await subResponse.json();

const charged = BigInt(subscription.total_charged);
const cap = BigInt(subscription.cap);
const percentage = Number((charged * 100n) / cap);

console.log(`Cap usage: ${percentage.toFixed(1)}% (${charged} / ${cap})`);

if (percentage > 80) {
  console.warn("⚠️ Approaching cap limit!");
}
```

### View Next Charge Date

```typescript
function estimateNextCharge(sub: Subscription, currentLedger: number): Date | null {
  if (!sub.next_charge_ledger || sub.status !== "active") {
    return null;
  }
  
  const ledgersUntil = sub.next_charge_ledger - currentLedger;
  if (ledgersUntil < 0) {
    return new Date(); // Chargeable now
  }
  
  const secondsUntil = ledgersUntil; // ~1 ledger/second
  return new Date(Date.now() + secondsUntil * 1000);
}

const nextCharge = estimateNextCharge(subscription, currentLedger);
if (nextCharge) {
  console.log(`Next charge: ${nextCharge.toLocaleString()}`);
} else {
  console.log("No upcoming charges (subscription inactive or exhausted)");
}
```

### List All Your Subscriptions

```typescript
async function getMySubscriptions(address: string) {
  const response = await fetch("https://api.stellar-subscriptions.io/subscriptions");
  const { subscriptions } = await response.json();
  
  return subscriptions.filter(sub => sub.subscriber === address);
}

const mySubs = await getMySubscriptions(subscriber.publicKey());
console.log(`You have ${mySubs.length} subscriptions`);

mySubs.forEach(sub => {
  console.log(`- ${sub.id}: ${sub.status}, ${sub.total_charged}/${sub.cap} charged`);
});
```

## Pausing Your Subscription

Temporarily suspend billing:

```typescript
const pauseOp = subscriptionContract.call("pause", subscriptionId);

const tx = new TransactionBuilder(account, {
  fee: "10000",
  networkPassphrase: Networks.TESTNET,
})
  .addOperation(pauseOp)
  .setTimeout(30)
  .build();

tx.sign(subscriber);
await server.submitTransaction(tx);

console.log("Subscription paused");
```

<CalloutBox type="info">
**While paused:**
- No charges will occur
- Your cap remains unchanged
- You can resume at any time
- The next charge ledger is recalculated when you resume
</CalloutBox>

## Resuming a Paused Subscription

```typescript
const resumeOp = subscriptionContract.call("resume", subscriptionId);

const tx = new TransactionBuilder(account, {
  fee: "10000",
  networkPassphrase: Networks.TESTNET,
})
  .addOperation(resumeOp)
  .setTimeout(30)
  .build();

tx.sign(subscriber);
await server.submitTransaction(tx);

console.log("Subscription resumed");
```

When you resume:
- Status changes back to `active`
- Next charge ledger is set to `current_ledger + interval_ledgers`
- Billing resumes from the resume point (not backdated)

## Cancelling Your Subscription

Permanently end a subscription:

```typescript
const cancelOp = subscriptionContract.call("cancel", subscriptionId);

const tx = new TransactionBuilder(account, {
  fee: "10000",
  networkPassphrase: Networks.TESTNET,
})
  .addOperation(cancelOp)
  .setTimeout(30)
  .build();

tx.sign(subscriber);
await server.submitTransaction(tx);

console.log("Subscription cancelled");
```

<CalloutBox type="danger">
**Cancellation is permanent.** You cannot undo it. To resubscribe, you must create a new subscription.
</CalloutBox>

## Understanding Subscription Status

| Status | What It Means | Can Be Charged? |
|--------|---------------|-----------------|
| `active` | Normal state, billing on schedule | ✅ Yes |
| `paused` | You paused it temporarily | ❌ No |
| `cancelled` | You cancelled it permanently | ❌ No |
| `exhausted` | Cap fully consumed | ❌ No |

## What If I Run Out of Tokens?

If your account doesn't have enough tokens when the merchant tries to charge:

1. **The charge fails** (transaction reverts)
2. **Your subscription remains active** — it's not automatically cancelled
3. **The merchant may retry** later when you have sufficient balance
4. **You should:**
   - Add tokens to your account if you want the service to continue
   - Cancel the subscription if you no longer want the service

## Security Tips

<CalloutBox type="success">
**DO:**
- Start with a small cap (3-6 billing cycles)
- Monitor cap usage regularly
- Cancel subscriptions you no longer use
- Verify contract addresses before subscribing
- Keep enough token balance for scheduled charges
</CalloutBox>

<CalloutBox type="danger">
**DON'T:**
- Set a cap much larger than needed
- Leave unused subscriptions active
- Ignore subscription monitoring
- Share your private key with anyone
- Assume merchants will cancel for you
</CalloutBox>

## Example: Subscription Dashboard

```typescript
class SubscriptionDashboard {
  constructor(private address: string) {}
  
  async getSummary() {
    const subs = await this.getMySubscriptions();
    
    const active = subs.filter(s => s.status === "active").length;
    const paused = subs.filter(s => s.status === "paused").length;
    const exhausted = subs.filter(s => s.status === "exhausted").length;
    
    const totalSpent = subs.reduce((sum, sub) => {
      return sum + BigInt(sub.total_charged);
    }, 0n);
    
    return {
      total: subs.length,
      active,
      paused,
      exhausted,
      totalSpent: totalSpent.toString(),
    };
  }
  
  async getAlertsNeeded() {
    const subs = await this.getMySubscriptions();
    const alerts = [];
    
    for (const sub of subs) {
      const usage = Number((BigInt(sub.total_charged) * 100n) / BigInt(sub.cap));
      
      if (usage > 90 && sub.status === "active") {
        alerts.push({
          type: "cap_warning",
          subscription: sub,
          message: `Subscription ${sub.id} is at ${usage.toFixed(1)}% of cap`,
        });
      }
      
      if (sub.status === "exhausted") {
        alerts.push({
          type: "exhausted",
          subscription: sub,
          message: `Subscription ${sub.id} has reached its cap`,
        });
      }
    }
    
    return alerts;
  }
  
  private async getMySubscriptions() {
    const response = await fetch("https://api.stellar-subscriptions.io/subscriptions");
    const { subscriptions } = await response.json();
    return subscriptions.filter(sub => sub.subscriber === this.address);
  }
}

// Usage
const dashboard = new SubscriptionDashboard(subscriber.publicKey());
const summary = await dashboard.getSummary();
const alerts = await dashboard.getAlertsNeeded();

console.log("Your subscriptions:", summary);
if (alerts.length > 0) {
  console.log("\n⚠️ Alerts:");
  alerts.forEach(alert => console.log(`- ${alert.message}`));
}
```

## Common Questions

### Can I increase my cap after subscribing?

Not in the current version. You'd need to:
1. Cancel the existing subscription
2. Create a new subscription with a higher cap

### What happens if the merchant charges too early?

The contract will reject the charge with `IntervalNotElapsed`. No tokens are transferred. This is enforced on-chain.

### Can a merchant prevent me from cancelling?

No. The `cancel()` function only requires your signature. Merchants have no ability to block it.

### Do I get refunds if I cancel early?

No automatic refunds. Any tokens already charged remain with the merchant. This is like cancelling Netflix mid-month.
